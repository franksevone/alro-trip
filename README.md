# ระบบ Web App กำหนดการเดินทาง (สำนักงานจัดรูปที่ดินกลาง: สจด.)

เว็บแอปพลิเคชันสำหรับแสดงและจัดการกำหนดการเดินทางตรวจราชการ รองรับการเปิดดูบนสมาร์ทโฟนและคอมพิวเตอร์ พร้อมระบบคำนวณเวลาอัตโนมัติ

---

## 🔗 ลิงก์เข้าใช้งานระบบ

| รูปแบบการแสดงผล | ลิงก์บนเครื่องคอมพิวเตอร์ | ลิงก์บนสมาร์ทโฟน (Wi-Fi วงเดียวกัน) |
| :--- | :--- | :--- |
| 🗺️ **1. แผนที่การเดินทาง (แบบไอคอน)** | [http://localhost:3000/map](http://localhost:3000/map) | `http://192.168.0.117:3000/map` |
| 📱 **2. แบบรายการกระชับ (Mobile-First)** | [http://localhost:3000](http://localhost:3000) | `http://192.168.0.117:3000` |
| ⚙️ **3. ระบบจัดการหลังบ้าน (Admin)** | [http://localhost:3000/admin](http://localhost:3000/admin) | `http://192.168.0.117:3000/admin` |

---

## 🌟 จุดเด่นของ "แผนที่การเดินทาง" (`/map`)
* **ดีไซน์เส้นทางท่องเที่ยว:**
  * แยกเส้นทางการเดินทางรายวัน Day 1 และ Day 2 ร้อยเรียงตามลำดับเวลา
  * ไอคอนประจำแต่ละจุดหมาย (สำนักงาน สจจ., ห้องประชุม, แปลงนาจัดรูปที่ดิน, เมนูกุ้งแม่น้ำ, วัด, ฝูงกวาง ฯลฯ)
* **การกดดูข้อมูลเชิงโต้ตอบ (Interactive Pop-up Modal):**
  * **แตะที่ไอคอนใดก็ได้** จะมีหน้าต่าง Pop-up แสดงข้อมูลแบบละเอียดขึ้นมาทันที
  * มีปุ่มนำทาง **Google Maps ↗**
  * มีปุ่ม **โทรออกหาผู้ประสานงาน**
  * แสดงภารกิจที่ต้องทำ และไฮไลต์สิ่งน่าสนใจ

---

ดับเบิลคลิกไฟล์ `start-app.bat` หรือรันคำสั่ง:
